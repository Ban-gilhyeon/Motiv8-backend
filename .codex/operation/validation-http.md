# 검증과 HTTP 상태 코드

## 입력 검증

- DTO 형식 오류와 필수값 누락은 `400 Bad Request`다.
- 숫자 입력은 음수·최대값·소수 허용 여부를 검증한다.
- 운동 방식에 맞지 않는 무게·횟수·시간 입력은 거부한다.
- DTO 검증을 통과해도 도메인 불변식은 Service 또는 Domain에서 재검증한다.

## 인증과 권한

- 토큰 누락·만료·위조는 `401 Unauthorized`다.
- 인증됐지만 리소스 접근 권한이 없으면 `403 Forbidden`이다.
- 다른 사용자의 리소스 존재 여부를 노출하지 않아야 하는 경우 `404` 정책을 검토한다.

## 리소스와 상태

- 리소스가 없으면 `404 Not Found`다.
- 중복 사용자·운동 종목 등 상태 충돌은 `409 Conflict`다.
- 정상 생성은 `201 Created`를 사용한다.
- 성공적인 삭제나 본문 없는 변경은 `204 No Content`를 검토한다.
- 처리하지 못한 시스템 오류는 `500 Internal Server Error`다.
