# 운동 기록 도메인

## 담당 범위

루틴, 실제 운동 기록, 운동 일지, 기간별 운동 통계를 관리한다.

## 핵심 개념

- Routine: 반복 수행할 운동 계획
- Set: 루틴 또는 기록 안의 한 세트
- Workout Record: 특정 날짜에 실제 수행한 결과
- Workout Journal: 날짜별 운동 기록 조회
- Volume: 기간 또는 부위별 누적 운동량
- Workout Session: 특정 날짜에 실제로 진행한 운동 세션

운동 기록은 선택한 운동 종목의 유형에 따라 입력 필드와 검증 규칙이 달라진다.

```text
WEIGHT      → 세트별 무게 + 반복 횟수
BODYWEIGHT  → 세트별 반복 횟수, 선택적 추가 중량
CARDIO      → 시간 중심, 필요 시 거리·속도·칼로리
```

## 비즈니스 규칙

- 루틴은 실제 수행 기록과 분리되어야 한다.
- 루틴 원본을 수정해도 과거 운동 세션과 기록이 변경되면 안 된다.
- 운동 시작 시 루틴 원본을 오늘의 운동 세션으로 구성하며, 세션에는 진행 상태와 경과 시간을 관리한다.
- 세션에는 운동별 진행 상태와 세트별 완료 상태를 저장한다.
- 전체 진행률은 우선 완료 세트 수를 전체 세트 수로 나누어 계산한다.
- 완료한 운동은 해당 운동의 모든 세트가 완료된 상태이며, 완료 취소가 가능해야 한다.
- 조회 화면의 필터는 표시 상태이며 원본 루틴이나 운동 기록을 삭제하지 않는다.
- 세트 추가 시 직전 세트의 설정값을 복사하고 미완료 상태로 시작한다.
- 웨이트의 무게·반복 횟수는 운동 단위가 아니라 세트 단위로 저장한다.
- 맨몸 운동은 `BODYWEIGHT` 유형을 유지하며 필요하면 세트별 추가 중량을 저장한다.
- 유산소 운동은 중량을 저장하지 않고 시간 중심으로 기록한다.
- 운동 기록은 사용자·운동 종목·수행 일시를 가져야 한다.
- 한 날짜에 여러 기록이 있으면 모두 일지와 통계에 포함한다.
- 기록 수정·삭제 시 통계와 연관 진행도를 재계산해야 한다.
- 기록이 없는 기간의 통계는 0 또는 빈 목록으로 일관되게 반환한다.
- 저장 실패 시 부분 저장이 남지 않도록 트랜잭션을 검토한다.

## 사용자 흐름

### 운동 기록 등록

1. 사용자가 인증한다.
2. 운동 종목 또는 루틴을 선택해 오늘의 운동 세션을 시작한다.
3. 세트별 무게·횟수·시간과 완료 상태를 입력한다.
4. 필요하면 오늘 세션에만 운동이나 세트를 추가한다.
5. 서버가 운동 방식과 입력값을 검증한다.
6. 기록을 저장하고 통계 원천 데이터로 반영한다.

### 운동 일지 조회

1. 사용자가 월 또는 기간을 선택한다.
2. 운동 기록이 있는 날짜를 반환한다.
3. 날짜 선택 시 해당 날짜의 세트 상세를 반환한다.

## 결정이 필요한 사항

- 운동량은 무게×횟수, 세트 수, 시간 중 무엇을 기준으로 할 것인가?
- 자동 저장 주기와 실패 복구 방식은 무엇인가?
- 추가한 운동·세트를 오늘 세션에만 반영할지 원본 루틴에도 반영할지 결정해야 한다.
- 유산소 운동의 거리·속도·칼로리와 세트 개념을 어떻게 저장할지 결정해야 한다.
- 운동 세션의 타이머 중단·재개와 유산소 진행률 산정 방식을 결정해야 한다.
