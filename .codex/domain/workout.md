# 운동 기록 도메인

## 담당 범위

루틴, 실제 운동 기록, 운동 일지, 기간별 운동 통계를 관리한다.

## 핵심 개념

- Routine: 반복 수행할 운동 계획
- Set: 루틴 또는 기록 안의 한 세트
- Workout Record: 특정 날짜에 실제 수행한 결과
- Workout Journal: 날짜별 운동 기록 조회
- Volume: 기간 또는 부위별 누적 운동량

운동 기록은 선택한 운동 종목의 유형에 따라 입력 필드와 검증 규칙이 달라진다.

```text
WEIGHT      → 무게 + 반복 횟수
BODYWEIGHT  → 반복 횟수 또는 세트
CARDIO      → 시간, 필요 시 거리·속도·칼로리
```

## 비즈니스 규칙

- 루틴은 실제 수행 기록과 분리되어야 한다.
- 운동 기록은 사용자·운동 종목·수행 일시를 가져야 한다.
- 한 날짜에 여러 기록이 있으면 모두 일지와 통계에 포함한다.
- 기록 수정·삭제 시 통계와 연관 진행도를 재계산해야 한다.
- 기록이 없는 기간의 통계는 0 또는 빈 목록으로 일관되게 반환한다.
- 저장 실패 시 부분 저장이 남지 않도록 트랜잭션을 검토한다.

## 사용자 흐름

### 운동 기록 등록

1. 사용자가 인증한다.
2. 운동 종목 또는 루틴을 선택한다.
3. 세트별 무게·횟수·시간을 입력한다.
4. 서버가 운동 방식과 입력값을 검증한다.
5. 기록을 저장하고 통계 원천 데이터로 반영한다.

### 운동 일지 조회

1. 사용자가 월 또는 기간을 선택한다.
2. 운동 기록이 있는 날짜를 반환한다.
3. 날짜 선택 시 해당 날짜의 세트 상세를 반환한다.

## 결정이 필요한 사항

- 운동량은 무게×횟수, 세트 수, 시간 중 무엇을 기준으로 할 것인가?
- 자동 저장 주기와 실패 복구 방식은 무엇인가?
