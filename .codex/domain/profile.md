# 프로필 도메인

## 담당 범위

사용자의 운동 성장 상태와 프로필 정보를 관리한다. 계정·인증은 Auth가 담당하고, 운동 기록은 Workout이 담당한다.

## 핵심 개념

- Profile: 사용자와 1:1로 연결된 운동 성장 프로필
- Experience: 운동 활동으로 얻는 누적 경험치
- Level: 누적 경험치 구간으로 계산하는 성장 단계
- Growth Stats: 어깨·팔·가슴·등·복근·하체·지구력·열정 8개 성장 수치
- Experience History: 경험치 지급 근거와 중복 지급 방지를 위한 이력

## 비즈니스 규칙

- 회원가입 성공 시 기본 Profile을 생성한다.
- 경험치 원천은 운동 기록이며, Profile API가 임의 경험치를 직접 수정하지 않는다.
- 경험치는 `totalExperience`를 원천값으로 사용하고 레벨은 정책에 따라 계산한다.
- 동일한 원천 타입과 원천 식별자로 경험치를 중복 지급하지 않는다.
- 경험치는 양수만 지급한다.
- 성장 수치는 실제 신체 능력이 아닌 동기부여용 점수다.
- 프론트엔드는 서버가 계산한 레벨·경험치·스탯을 표시한다.

## 현재 레벨 정책

```text
레벨 1: 0 EXP
레벨 2: 100 EXP
레벨 3: 300 EXP
레벨 4: 600 EXP
레벨 5: 1000 EXP
```

현재는 코드의 `LevelPolicy`로 관리하며, 운영 중 정책 변경이나 보상 연결이 필요해지면 DB 테이블로 전환한다.

## API

```text
GET /api/v1/profile
```

인증된 사용자의 Profile만 조회할 수 있다.
