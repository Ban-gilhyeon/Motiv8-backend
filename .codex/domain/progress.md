# Progress Domain

## Scope

운동 목표, 아바타 변화, 배지, 운동 추천을 관리한다.

## Concepts

- Goal: 주간 운동 횟수, 목표 무게 등 사용자가 설정한 기준
- Avatar Progress: 운동 성과를 보여주는 단계형 캐릭터 상태
- Badge: 목표 또는 특정 성취에 대한 보상
- Recommendation: 목표와 부족한 부위를 기준으로 한 운동 제안

## Rules

- 운동 기록은 목표 달성값과 아바타 진행도의 입력이다.
- 부위별 운동량이 기준 범위에 도달하면 아바타 단계가 변경될 수 있다.
- 아바타는 실제 신체 변화 측정값이 아니라 동기부여용 시각화다.
- 추천은 사용자의 목표와 최근 운동 데이터에 근거해야 한다.
- 초기 추천은 규칙 기반으로 구현하고 이후 고도화한다.
- 기록 삭제·수정으로 기준을 다시 충족하지 못하면 달성 상태 정책을 적용한다.

## Flow

1. 사용자가 목표를 설정한다.
2. 운동 기록 저장 시 목표 달성값을 갱신한다.
3. 부위별 운동량과 단계 기준을 비교한다.
4. 아바타·배지·추천 결과를 갱신한다.
