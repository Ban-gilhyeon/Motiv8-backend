# Social Domain

## Scope

친구 추가, 운동 기록 공유, 사용자 간 목표와 운동량 비교를 관리한다.

## Concepts

- Friend: 서로 연결된 사용자
- Sharing: 사용자가 공개하기로 한 운동 데이터
- Competition: 친구 간 운동 목표 또는 운동량 비교

## Rules

- 운동 기록은 기본적으로 비공개다.
- 사용자가 명시적으로 허용한 데이터만 친구에게 공개한다.
- 개인 신체 정보와 인증 정보는 경쟁·공유 대상이 아니다.
- 친구 관계와 기록 공개 권한을 분리한다.
- 차단 또는 연결 해제 시 상대방의 공유 데이터 접근을 제한한다.

## Initial Scope

친구·경쟁은 핵심 운동 기록 기능 이후 확장한다. 초기에는 도메인 경계와 공개 정책만 정의한다.

## Open Questions

- 친구 요청은 양방향 수락 방식인가?
- 공개할 기록 범위는 운동 횟수, 부위별 운동량, 목표 달성 여부 중 무엇인가?
- 경쟁 기간과 순위 산정 기준은 무엇인가?
