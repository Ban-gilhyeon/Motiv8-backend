# 조회와 Projection

## 단순 조회

상태 변경이나 복잡한 도메인 규칙이 없는 조회는 Prisma Projection으로 처리할 수 있다.

```text
Prisma 조회
→ 조회 전용 결과 타입
→ Response DTO
```

예시:

- 운동 종목 목록
- 달력에 표시할 운동 날짜
- 운동 기록 요약 목록
- 관리자용 단순 목록

## 핵심 도메인 조회

도메인 규칙이나 후속 상태 변경이 필요한 조회는 Repository Port를 통해 Domain Entity로 변환한다.

## 조회 규칙

- 필요한 필드만 select한다.
- 목록과 상세 조회 모델을 분리한다.
- 정렬 기준과 페이지네이션을 명시한다.
- 다른 사용자의 데이터를 반환하지 않도록 소유권 조건을 포함한다.
- 집계 쿼리는 결과 의미와 계산 기준을 문서화한다.
