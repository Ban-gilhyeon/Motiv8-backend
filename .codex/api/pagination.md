# 페이지네이션과 날짜 규칙

## 페이지네이션

- 목록 API는 기본적으로 pagination을 고려한다.
- 기본 page size와 최대 page size를 제한한다.
- 정렬 기준과 기본 정렬 방향을 API별로 명시한다.
- 초기에는 offset pagination을 사용하고, 데이터 규모가 커지면 cursor 전환을 검토한다.
- 목록 응답의 `meta`에는 현재 페이지, 크기, 전체 개수 또는 다음 페이지 여부를 담는다.

## 날짜와 시간

- 운동 기록의 기준 시각과 사용자의 표시 날짜를 구분한다.
- 서버 저장 시각과 사용자 지역 기준 날짜의 변환 정책을 명시한다.
- 날짜 범위 조회는 시작·종료 포함 여부를 문서화한다.
- 달력 조회는 사용자의 시간대에서 운동한 날짜를 기준으로 한다.

## 운동 일지

- 월별 조회는 운동 기록이 있는 날짜와 해당 날짜의 요약 정보를 제공한다.
- 날짜 상세 조회는 해당 날짜의 루틴과 세트별 운동 기록을 제공한다.
- 기록이 없는 날짜는 빈 결과로 반환하며 오류로 처리하지 않는다.
