# 프로젝트 개요

## 문제

기존 운동 애플리케이션은 기록과 수치를 제공하지만, 사용자가 운동을 계속해야 할 시각적·심리적 동기를 충분히 제공하지 못할 수 있다. 실제 신체 변화는 느리게 나타나기 때문에 운동을 중단하기 쉽다.

## 해결 방향

Motiv8은 운동 기록을 바탕으로 사용자의 캐릭터가 단계적으로 변화하도록 하여 운동 성과를 빠르고 직관적으로 보여준다. 운동 일지, 부위별 통계, 목표와 추천을 연결해 꾸준한 운동을 돕는다.

## 개발 목표

- 실제 사용 가능한 웹 서비스 구현
- Node.js 백엔드 실무 역량 확보
- 웹과 추후 모바일 앱이 함께 사용할 API 설계
- 인증·DB·테스트·로그·배포까지 경험
- 기능보다 문제 해결 과정과 설계 근거를 설명할 수 있는 포트폴리오 구축

## 초기 핵심 기능

1. 회원가입·로그인
2. 운동 종목 관리
3. 루틴 구성
4. 운동 기록
5. 날짜별 운동 일지
6. 부위별 운동 통계
7. 캐릭터 진행 상태

추천·알림·배지·친구 경쟁은 핵심 기록 데이터가 안정화된 뒤 확장한다.
