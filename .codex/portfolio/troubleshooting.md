# 트러블슈팅 기록

트러블슈팅은 문제가 발생했을 때 아래 형식으로 기록한다.

## 기록 형식

```md
## 문제 제목

### 상황

어떤 기능을 구현하거나 운영하던 중 어떤 문제가 발생했는가?

### 원인

로그, 테스트, 코드 분석을 통해 확인한 직접 원인은 무엇인가?

### 해결

어떤 선택을 했고, 왜 그 방법을 선택했는가?

### 검증

어떤 테스트·로그·API 호출로 해결을 확인했는가?

### 포트폴리오 포인트

문제를 통해 보여줄 수 있는 설계·디버깅·운영 역량은 무엇인가?
```

## 기록 대상

- 인증·소유권 오류
- 운동 기록 중복 저장
- 통계 계산 오류
- Prisma 관계·트랜잭션 문제
- 이벤트 중복·실패·재시도
- API 응답 성능 문제
- 로그로 원인을 찾은 장애
- 배포 환경과 로컬 환경 차이

확인되지 않은 추측이나 과장된 성능 수치는 기록하지 않는다.
