# 구현 기능 요약

## 초기 구현 예정

- 사용자 회원가입·로그인·JWT 인증
- 사용자 소유권 기반 운동 데이터 접근
- 운동 종목과 측정 방식 관리
- 반복 가능한 운동 루틴 구성
- 세트·횟수·무게·시간 기반 운동 기록
- 날짜별 운동 일지와 달력 조회
- 부위별 운동량 통계
- 운동 기록 기반 캐릭터 진행 상태

## 확장 예정

- 목표 설정과 달성률
- 부족한 부위 기반 운동 추천
- 운동 리마인드와 목표 달성 알림
- 배지·업적
- 친구 추가와 운동량 경쟁
- 웹 API 재사용 기반 모바일 앱 전환

## 작성 규칙

기능을 추가할 때 단순 endpoint 목록만 적지 않는다. 사용자 문제, 핵심 흐름, 본인이 구현한 범위, 검증 방법을 함께 기록한다.
