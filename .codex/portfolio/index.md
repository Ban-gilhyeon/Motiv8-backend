# 포트폴리오 문서 목록

포트폴리오 문서는 구현 과정에서 결정한 이유와 해결한 문제를 지원서·면접 설명으로 재사용하기 위한 문서다. 단순 작업 로그가 아니라 문제, 판단, 결과를 중심으로 작성한다.

- [프로젝트 개요](overview.md): 문제와 서비스 목표
- [기술 선택과 아키텍처 결정](architecture-decisions.md): 구조와 선택 이유
- [구현 기능 요약](feature-summary.md): 사용자 관점의 완성 기능
- [트러블슈팅](troubleshooting.md): 문제·원인·해결·검증

기능 구현이 완료될 때마다 관련 문서의 현재 상태를 갱신한다.
